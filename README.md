# Laboratorio ERT 2D — estudio de sensibilidad

Laboratorio de Métodos Electromagnéticos con [PyGIMLi](https://www.pygimli.org).
Se puede usar **en el navegador, sin instalar nada**, con Binder.

## Abrirlo en Binder

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/NinjaSaurio120/laboratorio-ert/HEAD?urlpath=lab/tree/prueba_rapida.ipynb)

**Clic en el botón "launch binder" de arriba**, o abre este enlace:
https://mybinder.org/v2/gh/NinjaSaurio120/laboratorio-ert/HEAD?urlpath=lab/tree/prueba_rapida.ipynb

- La primera vez Binder tarda **10–20 minutos** en preparar todo (instala PyGIMLi).
  Las siguientes veces suele abrir en 1–2 minutos.
- Primero abre `prueba_rapida.ipynb` y córrelo: debe decir **FUNCIONA**.
- Luego abre `Anexo_Laboratorio_2_ERT.ipynb` → menú **Run → Run All Cells**.

## Importante sobre Binder

- Si no tocas nada por ~10 minutos, la sesión **se cierra** y se pierde lo que no
  hayas descargado.
- Para guardar tus cambios o resultados: clic derecho sobre el archivo en el panel
  de la izquierda → **Download**. Los resultados quedan en la carpeta
  `resultados_ert/` (la última celda del notebook arma un `.zip`).
- Tiene ~2 GB de memoria: suficiente para este laboratorio.
